# 🧮 BMI Calculator

## 🚀 Project Overview

This project is a simple **BMI (Body Mass Index) Calculator** developed using Python.

The application calculates BMI based on the user's **weight and height** and provides a BMI category based on the calculated value.

The project is designed as a beginner-friendly Python application to demonstrate basic programming concepts such as user input, mathematical calculations, conditional statements, loops, and exception handling.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Accept weight from the user.
* Accept height from the user.
* Calculate Body Mass Index (BMI).
* Classify the calculated BMI into a category.
* Validate user input.
* Handle invalid inputs safely.
* Display the calculated BMI clearly.
* Provide a simple and user-friendly interface.

## 📊 BMI Calculation

The BMI is calculated using the following formula:

```text
BMI = Weight / (Height × Height)
```

Where:

* Weight is measured in kilograms.
* Height is measured in meters.

The application then uses conditional statements to determine the corresponding BMI category.
